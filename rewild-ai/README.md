# Rewild AI

Rewild AI is a platform concept for redirecting surplus food to verified charities,
orphanages, community kitchens, and agricultural networks.

## Current version

This repository contains the front-end interface:

- Animated futuristic landing page
- Interactive OpenStreetMap network map
- GPS location request
- AI-style matching interface
- Chat interface
- Account registration interface
- Company, charity, farm, and individual account types

## Important

This is not yet a production platform. It does not yet include:

- A real database
- Secure login
- Email verification
- Real-time chat
- Payment processing
- Passport or ID verification
- Company registry validation
- Food-safety compliance checks

## Production requirements

A production version must use:

- A secure backend and database
- Encrypted user sessions
- Multi-factor authentication
- A compliant KYC / identity-verification provider
- Secure document upload and deletion policies
- Role-based permissions
- Moderation and reporting tools
- Food-safety and local regulatory review

## Running locally

Open `index.html` in a browser, or use the VS Code Live Server extension.
